Question 1 使用 Foundry 實作文字與語音的 AI 解決方案

English Question

You need to convert written customer notifications into natural-sounding spoken audio that can be played over a phone system.

Which Azure Speech in Foundry Tools capability should you use?

  • Aspeaker recognition
  • Bspeech synthesis
  • Cspeech recognition
  • Dspeech translation

Answer: B. speech synthesis

中文題目

你需要將書面的客戶通知轉換成自然流暢的語音，讓電話系統可以播放。

你應該使用 Azure Speech 在 Foundry Tools 中的哪一項功能？

  • A說話者辨識 (speaker recognition)
  • B語音合成 (speech synthesis)
  • C語音辨識 (speech recognition)
  • D語音翻譯 (speech translation)

中文答案：B。語音合成 (speech synthesis)

中文詳解

本題的關鍵動作是把「書面文字」轉成「可播放的自然語音」。在 Azure Speech 服務中，這種由文字產生語音的能力稱為 語音合成 (speech synthesis)，也常稱為 文字轉語音 (text to speech, TTS)。 因此，當情境是電話系統要播放客戶通知、客服語音、提醒訊息或其他從文字稿產生的語音內容時，應選擇 speech synthesis。

這題容易混淆的地方在於四個選項都和語音有關，但方向不同。語音辨識 (speech recognition) 是把人說的語音轉成文字，方向剛好相反； 語音翻譯 (speech translation) 是把語音內容轉成另一種語言； 說話者辨識 (speaker recognition) 則是用聲音判斷或驗證說話者身分。 題目沒有要求辨識誰在說話，也沒有要求翻譯或將語音轉文字，所以正確答案只能是 B。

為什麼 B 正確

題目要求「written customer notifications」變成「spoken audio」，也就是文字輸入、語音輸出，正符合語音合成。

其他選項為什麼錯

A 是辨識說話者；C 是語音轉文字；D 是語音跨語言翻譯。三者都不符合文字轉語音的需求。

Question 8 識別 AI 模型的組件與配置

English Question

You have a Microsoft Foundry project that has a generative AI model deployment.

You need to ensure that responses generated by the model minimize costs and remain within a defined length.

Which parameter should you configure?

  • ATemperature
  • BMax Completion Tokens
  • CTop P
  • DModel version settings

Answer: B. Max Completion Tokens

中文題目

你有一個 Microsoft Foundry 專案，其中已部署 生成式 AI 模型。
