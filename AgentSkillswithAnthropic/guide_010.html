全課精華摘要

Agent Skills 是什麼？

Agent Skills 是一種輕量級開放標準格式，用來將重複性工作流、專業知識和新能力封裝成可攜帶、可組合、可漸進式載入的資料夾。

課程核心學習成果

  1. 理解 Skills 的設計理念：Progressive Disclosure、Context Window 保護、開放標準
  2. 掌握 Skill 結構：YAML Frontmatter + Markdown Body + /references + /scripts + /assets
  3. 在四個環境中使用 Skills：Claude.ai、Claude API、Claude Code、Agent SDK
  4. 區分 Skills 與其他組件：Tools（能力）、MCP（存取）、Subagents（隔離/平行）
  5. 建立和評估自訂 Skills：最佳實踐、Skill Creator、單元測試

Frontmatter 速查

欄位必填說明
name是小寫、連字號分隔、動詞+ing 形式、=目錄名
description是做什麼 + 何時用 + 觸發關鍵字
license否授權資訊
compatibility否環境需求
metadata否任意鍵值對
allowed-tools否預核准工具（實驗性）

品質檢查清單

Skill 發佈前檢查

  • [ ] YAML frontmatter 包含 name 和 description
  • [ ] name 與目錄名稱一致
  • [ ] name 使用小寫+連字號+動詞ing 形式
  • [ ] description 描述「做什麼」和「何時用」
  • [ ] SKILL.md 在 500 行以內
  • [ ] 詳細參考資料已移到 references/
  • [ ] 腳本依賴已明確列出
  • [ ] 腳本標註「執行」或「閱讀」用途
  • [ ] 路徑使用正斜線（/）
  • [ ] 參考保持一層深度
  • [ ] 超過 100 行的參考檔案有 TOC
  • [ ] 經過 Skill Creator 最佳實踐檢查
  • [ ] 有單元測試定義（queries + expected_behavior）
  • [ ] 在目標模型上測試通過
  • [ ] 收集過人工回饋
