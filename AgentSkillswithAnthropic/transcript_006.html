在這最後一課中，我們將使用 Claude Agent SDK 建立一個研究代理。該代理將使用技能，根據文件、GitHub 倉庫和網路搜尋來為開源工具建立學習指南。

Claude Agent SDK 是一種程式化方式來建立你自己的代理應用程式，使用與 Claude Code 相同的內部架構。

我們要建立的是一個通用研究代理。主代理能夠從多個來源研究資訊並綜合摘要。它會派遣三個不同的子代理：分析文件、分析和下載倉庫、以及透過網路搜尋研究資訊。

主代理提示詞：作為協調器，擁有三個子代理的存取權限。如果提供了技能，需要精確遵循技能的指示。我們要對有無技能的情況都做好規劃。

子代理設定：

  • Documentation Researcher（文件研究員）：使用 WebSearch 和 WebFetch，定位文件並以特定格式回傳發現
  • Repository Analyzer（倉庫分析器）：使用 WebSearch、Bash 指令（git clone）、檔案讀取能力
  • Web Researcher（網路研究員）：使用 WebSearch 和 WebFetch，搜尋相關內容

learning-a-tool 技能：這個技能引導主協調器，不在個別子代理中使用。目的是建立可預測的模式，讓主代理知道理想的工作流程以及如何派遣子代理。

技能定義了研究階段（指定每個子代理要找什麼）、內容組織（漸進式等級）和輸出格式（概述、資源、路徑和程式碼範例）。

程式碼實作：

  • 使用 uv init 初始化專案，添加 claude-agent-sdk、python-dotenv、asyncio
  • 設定 allowed_tools：Write、Bash、WebSearch、WebFetch、Task、Skill
  • 設定 mcp_servers：連接 Notion MCP 伺服器
  • 使用 AgentDefinition 定義子代理，包含描述、提示詞和工具配置
  • 使用 setting_sources 指定技能位置（user 目錄和 project 目錄）

重要注意事項：必須在 allowed_tools 中列出主代理和子代理需要的所有工具，否則子代理將無法使用。技能定義在 .claude/skills 資料夾中，檔案名必須為 SKILL.md。

實際示範 - MinerU 學習指南：MinerU 是一個開源 PDF 提取程式庫，不是 Claude 訓練資料中可能很了解的內容，需要外部研究。

流程：

  1. 先顯示計畫（類似 Claude Code 的 plan mode）
  2. 批准後，平行派遣三個子代理
  3. 子代理分別從文件、GitHub、網路教學收集資料
  4. 綜合建立完整學習指南：README、resources、code examples、learning path
  5. 使用 Notion MCP 伺服器將 resources.md 寫入 Notion 頁面

安全注意事項：目前允許 write 和 bash 指令不需使用者確認。下一步應建立類似 Claude Code 的使用者確認介面，以及代理和子代理的中斷機制（interrupts）。
