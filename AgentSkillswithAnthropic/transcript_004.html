在第一課中，Claude AI 使用 Excel 技能建立了顯示行銷結果的試算表。Excel 技能是 Anthropic 預建技能之一，還包括 PowerPoint、Word、PDF 技能，以及技能建立技能。讓我們來看看這些。

現在我們了解了技能如何融入整個 AI 生態系統，讓我們看看你可以在 Claude AI 和 Claude Desktop 中直接使用的預建技能，以及可以透過 Claude Code 等工具自行安裝的技能。

在 github.com/anthropic/skills 這個倉庫中，所有這些技能都已準備好供生產環境使用。

重要的是，這些技能分為兩類：用於 Microsoft Docs、PDF、PowerPoint 和 Excel 的「文件技能」（Document Skills）是內建的，在 Claude AI 中始終可用。其餘的是範例技能，你可以在 Claude 中開啟或關閉，但預設除了 skill-creator 之外都是關閉的。

先來分析 PowerPoint 技能。它有一個 SKILL.md 檔案以及其他參考檔案和資料夾，包含 YAML Frontmatter 的名稱和描述。這個技能可以建立、編輯、分析 PowerPoint 檔案的內容，並且有底層腳本可以執行。

記住，這些腳本不是一開始就執行的，而是只在需要時才載入和執行。

PowerPoint 技能可以處理很多事情：顏色、字體排版、設計原則、需求規格，以及當使用者未指定時可由 Claude 選擇的色彩調色盤。

接下來要介紹的是一個 meta 概念 — skill-creator。它是一個用於程式化建立技能的技能。不需要從零開始建立必要的檔案和資料夾結構，skill creator 可以為你完成。

skill-creator 的 SKILL.md 中明確指定了步驟，包含具體範例和可重用的技能內容模式。初始化技能時會執行底層 Python 腳本：init_skill（初始化）、package（打包）和 validate（驗證）。

回到 Claude，我們要結合內建技能、自訂技能和 MCP 伺服器。首先修改之前的行銷分析技能，從 CSV 改為使用 BigQuery（Google 的資料存儲服務），透過 MCP 伺服器連接。

接著使用 skill-creator 建立品牌指南技能，包含色彩調色盤、字體排版和 logo。Claude 知道如何設計，但技能真正發光的地方是你可以告訴 Claude 你的公司要怎麼做。

最後，我們結合三個技能：行銷資料分析技能（BigQuery）、品牌指南技能，以及內建的 PowerPoint 技能，建立了一個完整的工作流程：從 BigQuery 分析行銷資料，然後生成符合品牌風格的簡報。

結果是漂亮的投影片，包含效率分析、漏斗分析和執行摘要，所有顏色、字體和 logo 都符合公司規範。
