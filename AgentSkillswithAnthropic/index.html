課程說明

本短課程（Agent Skills with Anthropic）介紹如何設計、封裝與部署 Agent Skills（技能），涵蓋概念、工具整合（例如 Files API、Code Execution、MCP）、Skill 設計（SKILL.md）、以及使用 Claude Agent SDK 的實作範例。課程適合想把重複化流程工程化、並把專業知識作為可重複技能注入代理應用的學習者與產品/工程團隊。

教學建議：每節課可採用「概念講解 + 範例示範 + 實作練習」的節奏；教師可搭配課堂練習（如：建立最小可行 SKILL、寫測試 harness、在容器中模擬 Files API 流程）來鞏固學習效果。

逐字稿
3 Why Use Skills — Part II 延伸說明技能的結構、可攜性與可組合性，介紹進階揭露與實作建議，適合用於講解技能設計原則與範例分析。 導讀教學
逐字稿
4 Exploring Pre-Built Skills 介紹內建與預構建技能（例如 PowerPoint/Excel）與 skill-creator 工具的應用，並示範如何把 CSV 流程轉為 BigQuery + MCP，適合示範整合應用。 導讀教學
逐字稿
5 Skills with the Claude API 說明在 Messages API 環境下如何結合 Code Execution 與 Files API 來執行技能，包含上傳/下載檔案與容器運作的實務重點，適合做為 API 層面的技術講解。 導讀教學
逐字稿
6 Skills with the Claude Agent SDK 聚焦使用 Claude Agent SDK 建構 research agent 的實作流程：主代理/子代理分工、allowed_tools 與寫入 MCP 的範例，建議用於實作演練與 code walkthrough。 導讀教學
逐字稿
7 技能、工具、MCP 與子代理 釐清 Skills、Tools、MCP 與 Subagents 的職責與互動，建議以案例講解如何搭配使用並處理權限與上下文成本，適合用於概念架構教學。 導讀教學
逐字稿
8 Creating Custom Skills 深入探討 SKILL.md 結構、命名與測試策略，並提供生成練習題與時間序列分析等實例，適合用於技能設計工作坊與評審練習。 導讀教學
逐字稿
9 Agent Skills 與實務 總結技能設計與上線流程，強調從最小可行 Skill 出發、採漸進揭露並以監測驅動迭代；適合作為課程結尾的教學要點回顧。 導讀教學
逐字稿
