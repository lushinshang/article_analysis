繁體中文（台灣）

在第一課中，你看到了技能如何與 Claude AI 協同工作。現在，我們將使用 Claude API 來測試上一課製作的兩個技能。要在 Claude API 中使用技能，我們需要使用程式碼執行工具（Code Execution Tool）和檔案 API（Files API）。這將提供 Claude 檔案系統存取和 bash 執行能力。

重要注意事項：

  • 在 Claude AI 和 Claude Desktop 建立的技能不會與 Claude API 或 Claude Code 共用
  • 技能需要 Claude 能夠執行程式碼、建立和編輯文件、簡報、PDF 和報告，並操作檔案系統
  • 在 Claude API 中需要手動設定，而 Claude AI 和 Claude Desktop 已自動配置

Code Execution Tool（程式碼執行工具）：允許 Claude 在沙箱環境中執行 Bash 或 shell 指令。提供獨立的容器（Container）來執行程式碼和操作檔案系統。這對讀取技能、執行技能中的程式碼和處理檔案至關重要。

容器限制：

  • 有 RAM、磁碟、CPU 限制
  • Messages API 沙箱沒有網路連線（Claude AI/Desktop 有）
  • 提供預安裝的程式庫

Files API（檔案 API）：用於上傳和下載可在容器中運行的檔案。上傳輸入檔案、發送到容器、下載生成的檔案。

範例 1 - 生成練習題技能：

  1. 使用 Files API 上傳技能目錄，取得 skill ID
  2. 上傳 LaTeX 講義檔案
  3. 使用 Sonnet 模型，傳入 beta headers：skills、code_execution、files API
  4. 技能在 container 關鍵字參數中設定
  5. 模型偵測技能，先讀取 SKILL.md，然後漸進式載入 assets 中的範本
  6. 生成 Markdown 檔案，透過 file_id 下載
  7. 輸出包含：是非題、解釋題、程式碼題、應用題

範例 2 - 分析時間序列技能 + docx 技能：

  1. 上傳自訂技能，取得 skill ID
  2. 上傳零售銷售 CSV 檔案
  3. 同時使用自訂技能（skill ID + version）和 Anthropic 內建 docx 技能
  4. 模型讀取兩個 SKILL.md，分析資料，執行診斷和視覺化
  5. 使用 docx 技能建立 Word 文件
  6. 下載包含統計分析、圖表和視覺化的 Word 文件

技能管理：可以程式化地列出技能版本、刪除版本，然後刪除底層技能。

在這一課中，我們結合了 Messages API、Code Execution Tool、Files API 和技能，以程式化方式使用自訂技能。在下一課中，我們將轉到 Claude Code，了解如何在 .claude 資料夾中添加自訂技能。
