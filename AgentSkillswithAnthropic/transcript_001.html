What's exciting about skills is they're now an open standard, which means they have a standardized format that work with any skills compatible agent. So you can build your skills once and deploy them across multiple agent products.

Any skill should include a SKILL.md markdown file, which contains the skill's name, description, and main instructions. The main instructions can also refer to other files such as scripts, additional markdown files, and assets such as templates and images.

Skills are progressively disclosed to the agent, which means that the skill's name and description always live in your agent's context window, but the agent does not load the rest of the instructions into its context until a user request matches the skill's description. At that point, the agent might then additionally load the reference and asset files if needed as well.

技能是一組指示資料夾，用專業知識擴展代理的能力。

在本課程中，你將學習技能如何運作、建立技能的最佳實務，並為不同的使用案例建立技能，包括程式開發、研究、資料分析等等。

令人興奮的是，技能現在是一個開放標準，這意味著它們有一個標準化格式，可以與任何相容技能的代理一起工作。所以你可以一次建立技能，然後部署到多個代理產品中。

每個技能都應包含一個 SKILL.md Markdown 檔案，其中包含技能的名稱、描述和主要指示。主要指示也可以參考其他檔案，例如腳本、額外的 Markdown 檔案，以及範本和圖片等資源。

技能對代理採用漸進式揭露（Progressive Disclosure）的方式，這意味著技能的名稱和描述始終存在於代理的上下文窗口（Context Window）中，但代理不會將其餘指示載入上下文，直到使用者的請求符合技能的描述。此時，代理可能會根據需要額外載入參考和資源檔案。

要使用技能，你的代理需要一組基本工具：檔案系統存取（讀寫檔案）和 bash 工具（執行程式碼）。這些工具使代理能夠執行技能所需的任何指令。

你的代理可以結合技能與 MCP（Model Context Protocol）和子代理（Sub-agents）來建立強大的代理工作流程。例如，它可以使用 MCP 從外部來源取得資料，然後依靠技能來知道如何處理該資料或如何有效地擷取。它也可以將任務委派給具有隔離上下文的子代理，而子代理本身也可以使用技能來獲取專業知識。

在本課程中，我們將從 Claude AI 開始，建立一個行銷活動的技能並結合預建的 Excel 和 PowerPoint 技能。然後建立兩個用於內容建立和資料分析工作流程的技能，並使用 Claude API 測試。接著在 Claude Code 中使用技能來審查和測試程式碼。最後，使用 Claude Agent SDK 建立一個研究代理，用技能來整合研究結果。
