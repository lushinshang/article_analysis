1 必考觀念

資料切分 (Data Split)
ML 標準流程 (ML Operations)
  • 1. 準備 (Ingest)：收集資料。
  • 2. 清洗 (Clean)：去除非數值、補缺值 (Impute)、標準化 (Normalize)。
  • 3. 切分 (Split)：切成 70% 訓練 (Training) 、30% 考試 (Validation)。
  • 4. 訓練 (Train)：讓模型看題庫學找答案。
  • 5. 評估 (Evaluate)：拿沒看過的考試卷測驗準度。
資料切分補充：
通常隨機按「列 (rows)」切，確保每一列資料完整。
例題 ID 2
機器學習專案中，如何切割訓練與評估資料？
正確：B。
說明：必須按「列」切分以保留完整的特徵+標籤組合；按欄切分會讓資料破碎。
分類 vs 回歸 vs 分群
  • 分類 (Classification)：預測類別。
    • 指標：Accuracy, Precision, Recall, F1, AUC
    • 損失：Cross-Entropy (交叉熵)
  • 回歸 (Regression)：預測數值。
    • 指標：MAE, MSE, RMSE, R²
    • 損失：MSE (均方誤差)
  • 分群 (Clustering)：自動分組。
    • 指標：Silhouette (輪廓係數), Elbow (手肘法)
    • 距離：Euclidean (歐基里德)
  • 優化與調校 (Optimization) • 防過擬合 (Overfitting)：L1/L2 Regularization (正規化), Dropout。
    • 梯度異常：用 ReLU (防消失), Batch Norm, Clipping (防爆炸)。
指標 (Metrics)：考試分數，越高越好 (如 Accuracy)。
損失 (Loss)：答錯的代價，越低越好 (如 MSE)。
例題 ID 59
建立 K-means 分群模型時，所有特徵的資料類型必須是？
正確：C (Numeric)。
說明：K-means 依靠計算距離，只有數值才能運算距離。文字需轉向量。
混淆矩陣 (Confusion Matrix)
  • TP (真陽性)：有病，測出有病 (正確)。
  • TN (真陰性)：沒病，測出沒病 (正確)。
  • FP (偽陽性)：沒病，誤測有病 (誤報/False Alarm)。
  • FN (偽陰性)：有病，誤測沒病 (漏報/Miss)。
  • 準確率 (Accuracy)：整體考幾分？所有預測正確（TP+TN）佔總數的比例。
  • 召回率 (Recall)：有無漏網之魚？實際是「Yes」的，被你抓出多少？(TP / TP+FN)
  • 精準率 (Precision)：是否亂槍打鳥？你說是「Yes」的，有多少是真的？(TP / TP+FP)
例題 ID 58
如何減少分類模型的 False Positives (偽陽性)？
正確：D。
說明：提高判斷門檻會減少偽陽性，但副作用是增加偽陰性 (Trade-off)。
負責任 AI (Responsible AI)
  • 公平性 (Fairness)：不歧視性別/種族。
  • 可靠安全 (Reliability)：容錯、錯誤處理。
  • 透明性 (Transparency)：可解釋、可理解原因。
  • 隱私安全 (Privacy)：保護數據資料。
  • 包容性 (Inclusiveness)：無障礙。
  • 當責性 (Accountability)：人要負責。
例題 ID 60
貸款 App 需「記錄核准或拒絕的原因」並告知申請人？
正確：A。
說明：解釋「為什麼」是透明度的核心。
Automated ML vs Designer
  • Automated ML (AutoML)：自動化！適合不懂演算法的人。只需提供資料，它自動幫你試演算法與參數。支援分類、回歸、時間序列預測。
  • Azure ML Designer：視覺化！拖拉 (Drag-and-drop) 模組來建立管線。不需寫程式碼 (No-code)。
例題 ID 139
您需要使用 Azure Machine Learning 訓練回歸模型，且您不具備 Python 或 R 的技能，應使用哪種開發選項？
正確：D。
說明：題目強調「不具備程式技能」，且要自己「訓練模型」，Designer 的拖拉介面最適合。AutoML 雖然也自動，但 Designer 是視覺化建構流程的首選。
推論管線與端點 (Inference)
  • 即時推論 (Real-time)：需要馬上得到結果。部署到 AKS 或 Managed Online Endpoint。
  • 批次推論 (Batch)：累積一堆資料，離線一次處理。部署到 Batch Endpoint。
例題 ID 72
您使用 Designer 建立並發佈了推論管線。若要從應用程式取用該管線，需要哪兩項資訊？
正確：C, D。
說明：要呼叫 Web Service，必須要有網址 (REST endpoint) 和鑰匙 (Key)。
AutoML 模型集成 (Ensemble Methods)

AutoML 會自動結合多個演算法來提升準確度，主要有兩種手段：

  • Voting Ensemble (投票集成)：採用「加權平均 (Weighted Average)」的方式。就像三個臭皮匠，投票表決 (Soft Voting)。
  • Stacking Ensemble (堆疊集成)：訓練一個「元模型 (Meta-model)」來整合其他模型的預測。就像請一個諸葛亮來統整大家的意見。
模擬試題 (自製)
Azure Automated ML 使用哪種集成技術，是透過訓練一個額外的「元模型 (Meta-model)」來優化多個模型的預測結果？
正確：B。
說明：Stacking 的核心就是訓練一個 Meta-model 來決定如何組合；Voting 則是計算加權平均。

2 必背重點（關鍵字服務對應）

Computer Vision (電腦視覺)
  • 收據 (Receipts)、發票 → Document Intelligence
  • 人臉、表情、身份驗證 → Face API
  • 一般物件偵測、描述圖片 → Computer Vision
  • 自訂商標、特定的花種 → Custom Vision
例題 ID 53
使用「預建收據模型 (Prebuilt receipt model)」應選擇哪項服務？
正確：A。
說明：Document Intelligence 屬於 Azure AI Services 家族；Computer Vision 無收據模型。
Azure Machine Learning (AML)
  • Workspace：最上層資源。
  • Job：執行的任務單位 (執行訓練腳本)。
  • Compute Instance：開發用 (單機)。
  • Compute Cluster：訓練用 (多節點)。
  • Inference Cluster (AKS)：生產環境即時推論。
例題 ID 47
使用 Azure ML Studio 用 Automated ML 建模型前，必須最先建立什麼？
正確：A。
說明：Workspace 是所有資源的容器，是第一步。
Azure OpenAI / GenAI
  • Limited Access：因負責任 AI 原則，使用前需申請批准。
  • Fine-tuning：拿自己的資料對現有模型進行微調。
  • Capabilities：生成、摘要、分類、翻譯、寫程式。
例題 ID 109
使用 Azure OpenAI 之前必須做什麼？
正確：B。
說明：基於負責任 AI 原則，微軟實施受限存取 (Limited Access) 政策。

3 常見題型速查

負責任 AI 關鍵字配對
  • 貸款核准 / 解釋原因 (Loan approval / Explaining) → Transparency (透明)
  • 種族 / 性別 / 偏見 (Race / Gender / Bias) → Fairness (公平)
  • 錯誤處理 / 缺失值 (Error handling / Missing values) → Reliability (可靠)
  • 螢幕報讀軟體 / 無障礙 (Screen reader / Accessibility) → Inclusiveness (包容)
部署環境選擇
  • 測試 / 開發 → Compute Instance
  • 即時 / 大量 / 線上 (Real-time) → AKS / Managed Endpoint
  • 非即時 / 批量 (Batch) → Batch Endpoint
NLP 任務
  • 情緒 (Sentiment) / 關鍵詞 → Text Analytics
  • 聊天機器人 → Bot Service + QnA Maker
  • 理解意圖 (Intent) → LUIS / CLU
  • 翻譯 → Translator
生成式 AI (Generative AI)
  • LLM (大型語言模型)：核心是「文字」。輸入 Prompt，輸出也是文字。
  • 接地 (Grounding)：把知識貼到 Prompt 裡，減少幻覺。
  • DALL-E：畫圖 (Create)、修圖 (Modify)。非分析圖片！
  • Content Filtering：過濾仇恨、暴力等不當內容。

5 考前衝刺清單

  • Responsible AI 六原則能背出並舉例。
  • 看到題幹先判斷資料型態，再對應服務（速配表）。
  • 會從混淆矩陣抓 TP/FP/FN/TN，算 Precision/Recall/F1。
  • AutoML 支援分類/回歸/時序，不支援分群；Designer 是拖拉，Notebook 自寫程式。
  • 部署：CI 測試、Cluster/AKS 線上、Batch 離線大量。
  • OpenAI：記住資源名+部署名+API 版本，內容安全要過 Moderation。
