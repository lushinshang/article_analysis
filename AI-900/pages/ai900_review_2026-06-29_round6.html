生成式 AI 題要看問法

本輪 9 題錯題明細

Q1Semantic Segmentation

根據影像中代表的物件，分類影像中的個別圖元。

你的答案影像分類
正確答案語意分割
個別圖元就是像素級分類。影像分類是替整張圖片貼類別，不會細到每個像素。

口訣：每個像素 = 語意分割；整張圖 = 影像分類。

Q6Knowledge Mining

改善文件搜尋與索引，讓影像等文件中的文字可搜尋。

你的答案交談式 AI
正確答案數據挖掘
題目核心是搜尋、索引與大量文件探索，這是知識挖掘/數據挖掘，不是聊天平台。

口訣：搜尋 + 索引 + 文件內容 = 數據挖掘。

Q9Responsible AI

評估並減輕模型特徵所引入的偏差。

你的答案透明度
正確答案公平性
偏差、歧視、不公平結果都指向公平性。透明度是說明目的、運作方式與限制。

口訣：偏差 = 公平性；限制講清楚 = 透明度。

Q11Logistic Regression

依年齡與體脂百分比識別人類患糖尿病的機率。

你的答案線性回歸
正確答案邏輯斯迴歸
雖然有機率數字，但題目本質是是否患病或風險類別的分類決策，AI-900 以邏輯斯迴歸作答。

口訣：機率 + 類別決策 = 邏輯斯迴歸。

Q12Regression

根據專案功能預測與專案相關聯的數值標籤。

你的答案分類
正確答案回歸
題目明確說數值標籤，答案就是回歸。分類是預測預先定義的類別。

口訣：數值 = 回歸；類別 = 分類。

Q19Azure ML Designer

Azure Machine Learning designer 中用哪個演算法模組來訓練模型？

你的答案評估模型
正確答案線性迴歸
線性迴歸是訓練回歸模型的演算法模組。評估模型是訓練完成後用來測量表現的元件。

口訣：訓練演算法 = 線性迴歸；訓練後檢查 = 評估模型。

Q26Image Description

Azure Vision 影像描述任務中，每個短語包含哪項額外資訊？

你的答案邊界框座標
正確答案信賴分數
影像描述會產生短語並附上信賴分數。邊界框座標是物件偵測的輸出。

口訣：描述 = 信賴分數；偵測 = 邊界框。

Q35Entity Linking

Azure Language 哪個功能可回傳外部網站連結以消除術語歧義？

你的答案語言偵測
正確答案實體辨識
外部連結與消除歧義其實是在考實體連結；選項若只有實體辨識，就選實體辨識。

口訣：外部連結/Wikipedia/消歧義 = 實體連結；沒有就選實體辨識。

Q45Generative AI

生成式 AI 常見的兩種場景。

你的答案摘要、翻譯
正確答案影像產生、摘要
影像產生與摘要都明確產生新內容。翻譯可由生成式模型完成，但在這類題目常歸入 NLP/Translator。

口訣：常見生成式 AI 場景 = 影像產生 + 摘要。
