本輪 8 題錯題明細

Q5Azure Vision

Azure Vision in Foundry Tools 包含哪兩項 AI 工作負載功能？

你的答案實體辨識、空間分析
正確答案OCR、空間分析
Vision 是看影像，OCR 和空間分析屬於 Vision。實體辨識是 Azure Language 的文字分析功能。

口訣：Vision 這題只選 OCR + 空間分析；實體、情感、關鍵片語都是 Language。

Q10Responsible AI

無人駕駛農業車輛與田裡工作的人一起部署，哪個原則最重要？

你的答案包容
正確答案可靠性和安全性
AI 控制機械並和真人共享實體環境，核心風險是人身安全。

口訣：AI 控制車輛/機械 + 真人在旁邊 = 可靠性和安全性。

Q19AutoML

Automated ML 可訓練哪三種監督式機器學習模型？

你的答案分類、叢集、回歸
正確答案分類、回歸、時間序列預測
叢集是非監督式學習，不屬於這題的監督式模型。

口訣：AutoML 監督式三件套 = 分類 + 回歸 + 時間序列預測。

Q22Computer Vision

哪個電腦視覺服務在輸出中提供邊界座標？

你的答案語意分割
正確答案物件偵測
邊界座標就是框出物件位置。語意分割是把每個像素分類。

口訣：框出位置 = 物件偵測；像素分類 = 語意分割。

Q29Azure Face

分析人物影像，判斷人類相關視覺特徵，應使用哪個工具？

你的答案Azure Vision in Foundry Tools
正確答案Azure AI Face in Foundry Tools
人物影像的人類相關視覺特徵，尤其是以臉為中心的分析，要選 Face。

口訣：人物臉部特徵 = Face；一般影像內容 = Vision。

Q33Azure Language

從支援問題資料辨識問題，以及辨識提及的人員與產品，要用哪兩項功能？

你的答案CLU、具名實體辨識
正確答案關鍵片語擷取、具名實體辨識
常見問題和主要交談點用關鍵片語擷取；人員、產品、地點、組織用具名實體辨識。

口訣：問題重點 = 關鍵片語；人員產品 = NER；意圖判斷才是 CLU。

Q34Language Detection

Azure Language 語言偵測會回傳哪三個值？

你的答案邊界框座標、ISO 639-1、分數
正確答案ISO 639-1、語言名稱、分數
語言偵測只回答文字是哪種語言與信心分數。邊界框座標是 Vision。

口訣：語言偵測 = 語言名稱 + ISO 639-1 + 分數。

Q47Azure OpenAI

Azure OpenAI in Foundry Models 支援哪種安全能力？

你的答案用戶端加密金鑰
正確答案Azure RBAC
題目問的是模型存取與操作權限，所以是 Azure role-based access control。

口訣：Azure OpenAI + Foundry + 存取控制 = RBAC。

本輪已穩定題型

  • NLP / Speech：即時字幕 = Speech；情感分析 = 判斷正負面；實體連結 = 提供更多線上資訊。
  • Machine Learning：數值預測 = 回歸；預先定義類別 = 分類；相似分組 = 叢集。
  • Computer Vision：OCR 讀圖中文字；X 光骨折類型 = 影像分類；標記 = 影像摘要屬性元資料。
  • Generative AI：系統訊息控制條件約束與樣式；DALL-E 產生影像；Embeddings 比較文字相似度。
  • Foundry：模型目錄可發現與比較模型；Foundry 平台可打造、客製化並管理 AI 應用程式與代理。
  • Responsible AI：問責 = 道德法律治理；公平性 = 貸款/種族/性別偏見；醫療資料 = 問責 + 隱私權和安全性。
