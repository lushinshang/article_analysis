錯題逐題復盤

Q6Azure Vision

Azure Vision in Foundry Tools 包含哪兩項 AI 工作負載功能？

你的答案實體辨識、OCR
正確答案OCR、空間分析
Vision 是看圖；Language 是看文字。實體辨識、關鍵片語、情感分析都屬於 Azure Language，不是 Azure Vision。

口訣：Vision = OCR + 空間分析 + 影像；Language = 實體 + 關鍵片語 + 情感。

Q16Azure ML

使用 Azure Machine Learning 訓練迴歸模型，應該在 Studio 建立什麼？

你的答案Azure 容器實例
正確答案作業 Job
訓練模型時要建立作業。Azure Container Instances 和 AKS 是模型訓練完成後的部署目標。

口訣：訓練是 Job；部署才是 ACI/AKS。

Q18AutoML

Automated ML 可訓練哪三種監督式機器學習模型？

你的答案分類、叢集、回歸
正確答案分類、回歸、時間序列預測
題目強調監督式模型。叢集是非監督式，不能放進這組答案。

口訣：AutoML 監督式三件套 = 分類 + 回歸 + 時間序列預測。

Q22Computer Vision

哪個電腦視覺服務在輸出中提供邊界座標？

你的答案語意分割
正確答案物件偵測
邊界座標就是框出物件位置。語意分割不是畫框，而是把每個像素分類。

口訣：框出位置 = 物件偵測；每個像素分類 = 語意分割。

Q26Azure Vision

Azure Vision 支援哪兩個專門領域模型？

你的答案動物、汽車
正確答案名人、地標
這題不是問 Vision 能看到什麼，而是問內建的專門領域模型。

口訣：Azure Vision 專門領域模型 = 名人 + 地標。

Q28Azure Face

Face Detect API 判斷戴眼鏡或頭巾，應使用哪項功能？

你的答案臉部識別
正確答案臉部屬性
眼鏡、面具、頭飾是臉上的特徵或配件，屬於臉部屬性。臉部識別是在問這個人是誰。

口訣：配件 = 臉部屬性；這個人是誰 = 臉部識別。

Q31Knowledge Base

哪些檔案可匯入，產生 Microsoft Foundry 代理知識庫？

你的答案CSV、DOC
正確答案DOC、PDF
這題考文件型知識庫。CSV 是表格資料，不是這題要的文件匯入格式。

口訣：知識庫吃文件，先記 DOC + PDF。

Q37Azure Language

要線上提供更多關於文字實體的資訊，該用什麼？

你的答案具名實體辨識
正確答案實體連結
具名實體辨識只是找出人名、地名、組織。實體連結會釐清實體身分，並提供線上更多資訊。

口訣：找出來 = NER；連出去 = Entity Linking。

Q42Responsible AI

確保使用者了解生成式 AI 解決方案目的與輸出影響，應減輕哪種風險？

你的答案偏見或不公平結果
正確答案缺乏透明度
題目不是問有沒有偏袒某些族群，而是問使用者是否理解目的、使用方式與輸出影響。

口訣：目的、使用方式、限制、影響要講清楚 = 透明度；族群差別待遇 = 公平性。

Q48Microsoft Foundry

哪句話最準確描述 Microsoft Foundry？

你的答案用於發現與比較 Azure 中可用的生成式 AI 模型
正確答案整合建構、測試及部署生成式 AI 解決方案的工具與服務
發現與比較模型是「模型目錄」的功能；Foundry 平台本身範圍更大，是端對端開發平台。

口訣：Foundry 平台 = 建構 + 測試 + 部署；模型目錄 = 發現 + 比較模型。

服務邊界速查

服務/概念 看到這些線索就選它 容易誤選
Azure Vision OCR、影像描述、物件偵測、空間分析、名人、地標 實體辨識、情感分析
Azure Face 臉部屬性、臉部矩形、臉部標記點、臉部識別 一般物件偵測
Custom Vision 自己訓練影像分類或物件偵測模型 一般 Azure Vision
Azure Language 情感分析、具名實體辨識、實體連結、PII、關鍵片語、語言偵測 Azure Vision、Content Safety
Azure ML 訓練模型建立 Job；Designer 先建管線；部署用 ACI/AKS 把部署目標當訓練作業
Microsoft Foundry 建構、測試、部署、管理 AI 應用與代理 模型目錄的發現與比較

  • Azure Vision 專門領域模型只記：名人 + 地標。
  • AutoML 監督式三件套：分類、回歸、時間序列預測。
  • 訓練模型是 Job；部署模型才是 ACI/AKS。
  • 找出實體是 NER；提供更多線上資訊是實體連結。
  • 目的、限制、輸出影響要讓使用者知道，就是透明度。
