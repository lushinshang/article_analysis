Q4Azure Vision

Azure Vision in Foundry Tools 包含哪兩項 AI 工作負載功能？

你的答案實體辨識、空間分析
正確答案OCR、空間分析
OCR 與空間分析屬於 Vision。實體辨識、關鍵片語、情感分析都是 Azure Language 的文字理解功能。

口訣：Vision = OCR + 空間分析；Language = 實體 + 關鍵 + 情感。

Q11Logistic Regression

依年齡與體脂百分比識別人類患糖尿病的機率。

你的答案線性回歸
正確答案邏輯斯迴歸
題目雖然寫機率的數值，但糖尿病風險是是否患病、是否高風險這類分類決策。AI-900 固定選邏輯斯迴歸。

口訣：糖尿病機率 = 邏輯斯迴歸。

Q18Training Flow

準備數據集和定型機器學習模型之前，應該怎麼做？

你的答案清除遺漏的數據
正確答案將數據分割成定型和驗證數據集
訓練前先切訓練集與驗證集。清缺值、正規化、摘要資料是資料轉換，不是這題的流程答案。

口訣：訓練前先切資料；訓練集學習，驗證集小考。

Q35Translator

Azure Translator in Foundry Tools 支援哪種類型的翻譯？

你的答案語音到語音翻譯
正確答案文字到文字翻譯
Translator 處理文字到文字。語音轉文字、文字轉語音、語音到語音都屬於 Speech 相關能力。

口訣：Translator = 文字到文字；Speech = 語音相關。
