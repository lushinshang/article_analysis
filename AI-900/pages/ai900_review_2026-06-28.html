白話補課：先把題目翻成人話

1. 回歸、分類、叢集怎麼分？

先問自己：「我要模型猜的是什麼？」如果答案是價格、數量、分數這種數字，就是回歸。如果答案是貓/狗、通過/不通過、正面/負面這種類別，就是分類。如果題目說要把相似的人或資料自動分成幾群，而且沒有先給答案，就是叢集。

考場口訣：數字 = 回歸；類別 = 分類；相似分組 = 叢集。

2. 訓練集、驗證集為什麼都有標籤？

訓練集像「有答案的習題」，模型靠它學。驗證集像「另一份有答案的小考」，用來檢查模型有沒有真的學會。所以兩者都要有已知特徵和已知標籤。真正上線預測時，才會只有特徵、讓模型猜標籤。

看到 Training / Validation dataset，記得：都有已知特徵 + 已知標籤。

3. OCR、物件偵測、語意分割差在哪？

OCR 是「讀圖裡的字」，例如手寫簽名、醫療紀錄、招牌文字。物件偵測是「找圖裡有什麼，而且在哪裡」，例如找牲畜、車輛、貨架商品。語意分割更細，是把每個像素都分到某一類。

考場口訣：讀字 OCR；找位置物件偵測；切像素語意分割。

4. Azure Language 不等於所有語言相關服務

Azure Language 主要處理文字分析，例如情感分析、實體連結、PII 偵測、語言偵測。Translator 和 Speech 是另外的服務。題目若問「單一端點和金鑰存取 Translator + Speech」，不要選 Azure Language，要選整合式的 Foundry / Azure AI Services 類資源。

Language = 文字分析；Translator = 翻譯；Speech = 語音。

5. 生成式 AI 的幾個高頻字

系統訊息是拿來設定模型的角色、限制、語氣、格式。Embeddings 是把文字變成向量，所以能做語意搜尋、分類、相似度比較。Azure OpenAI in Foundry Models 的存取控制，考場常用 Azure RBAC。

限制風格 = 系統訊息；比較相似 = Embeddings；權限管理 = RBAC。

6. Responsible AI 先看關鍵字

題目說「讓使用者知道目的、限制、影響」，就是透明度。題目說醫療資料、個資，就是隱私權與安全性。題目說自駕、機械、人身安全，就是可靠性與安全性。題目說法律、道德、誰負責，就是問責。

目的限制 = 透明度；個資 = 隱私；人身安全 = 可靠安全；法律道德 = 問責。

Q6Responsible AI

哪個原則會提高對 AI 解決方案限制的認識？

你的答案可靠性和安全性
正確答案透明度
白話理解可靠性和安全性是在問「系統會不會出錯、會不會傷人」。這題問的是「大家知不知道 AI 的限制」，重點是把事情講清楚，所以是透明度。

記憶點：只要題目出現「目的、運作方式、限制、影響要讓使用者了解」，優先選透明度。

Q11Machine Learning

根據功能預測與專案相關聯的數值標籤，是哪種演算法？

你的答案聚類
正確答案回歸
白話理解題目說要預測「數值標籤」。只要模型最後要猜一個數字，例如價格、數量、分數、溫度，就是回歸。叢集是沒有答案時，把相似資料自動分群。

記憶點：數值預測是回歸；類別預測是分類；把相似資料分組才是叢集。

Q12Regression

多重線性回歸模型應滿足哪個假設，以避免誤導性預測？

你的答案標籤彼此獨立
正確答案功能彼此獨立
白話理解多元線性回歸是用很多個輸入欄位去預測一個答案。這些輸入欄位如果彼此高度重複，模型會被誤導，所以題目考的是「特徵彼此獨立」。

記憶點：多元線性回歸是一個標籤對多個特徵；考的是特徵之間不要高度相依。

Q14Dataset

回歸演算法中，驗證資料集的特徵與標籤具備什麼特性？

你的答案未知的特徵值和已知的標籤值
正確答案已知特徵值與標籤值
白話理解驗證集不是正式上線資料，而是有答案的小考。你要知道正確答案，才知道模型猜得準不準，所以特徵和標籤都要已知。

記憶點：訓練與驗證都需要已知特徵和已知標籤；真正預測時才是只給特徵、模型輸出標籤。

Q15Dataset

回歸演算法中，訓練資料集的特徵與標籤具備什麼特性？

你的答案未知的特徵值和已知的標籤值
正確答案已知特徵值與標籤值
白話理解訓練模型就像教學生做題目。學生要看題目，也要看答案，才知道規則。因此訓練資料一定同時有輸入特徵和正確標籤。

記憶點：訓練資料一定是已知輸入與已知答案，模型才能學習特徵和標籤之間的關係。

Q18AutoML

建立自動化 ML 模型時，在 Azure Machine Learning studio 應先建立哪個資源？

你的答案工作區
正確答案資料集
白話理解這題容易被「先建立工作區」騙到。題目已經說你在 Azure Machine Learning studio 建立 AutoML 模型，通常代表工作區環境已經有了。AutoML 回合真正需要先準備的是資料集。

記憶點：能進入 Studio 代表工作區通常已存在；建立 AutoML 回合的前置重點是資料集。

Q19Designer

使用 Azure Machine Learning designer 從新訓練模型部署預測服務，應先做什麼？

你的答案新增訓練模組
正確答案建立推斷管線
白話理解題目說「新訓練的模型」和「部署預測服務」，表示訓練已經做完了。接下來要讓外部丟資料進來拿預測結果，所以要建立推斷管線。

記憶點：訓練完成後要部署服務，流程會從訓練管線轉成推斷管線。

Q22Computer Vision

哪個程序可讓你使用物件偵測？

你的答案從手稿中擷取文字
正確答案在田野中追蹤牲畜
白話理解手稿是文字，所以是 OCR。追蹤牲畜要在畫面中找到動物，通常還要知道牠在哪個位置，這就是物件偵測。

記憶點：影像文字是 OCR；找出影像中的物件與位置，例如牲畜、人、車，才是物件偵測。

Q25Azure Vision

Azure Vision 在 Foundry Tools 中消除了機器學習流程的哪三個環節？

你的答案Azure 資源供應配置、評估模型、推斷
正確答案選擇模型、評估模型、訓練模型
白話理解Azure Vision 是現成服務，像是微軟已經幫你訓練好的模型。你不用自己挑模型、訓練模型、評估模型；但你還是要建立 Azure 資源，也還是會拿圖片去做推斷。

記憶點：預先訓練服務省掉模型選擇、訓練、評估；使用時仍要建立資源，也仍要進行推斷。

Q34Language Detection

Azure Language 語言偵測會回傳哪三個值？

你的答案周框方塊座標、語言名稱、分數
正確答案ISO 639-1 程式碼、語言名稱、分數
白話理解語言偵測只看文字屬於哪種語言，所以會回傳語言名稱、語言代碼和信心分數。周框方塊是畫在圖片上的座標，屬於電腦視覺。

記憶點：語言偵測回傳語言資訊；周框方塊座標屬於視覺任務，例如物件偵測。

Q35Speech

語音轉文字 API 的通用語言模型針對哪兩個案例最佳化？

你的答案聽寫、發音
正確答案會話、聽寫
白話理解通用 Speech to text 模型主要是處理一般人講話和口述內容，也就是會話與聽寫。發音評量比較像專門用途，不是通用模型的標準最佳化場景。

記憶點：Speech to text 通用模型記「會話 + 聽寫」；發音、特定聲音或語言情境通常要自訂模型。

Q36Azure AI Services

哪個 Azure 資源能用單一端點和金鑰存取 Translator 與 Speech？

你的答案Azure Language in Foundry Tools
正確答案Microsoft Foundry
白話理解Azure Language 是文字分析服務，不是萬用入口。題目同時提到 Translator 和 Speech，而且強調單一端點與金鑰，表示要選整合式資源。

記憶點：Azure Language 只對應語言服務；Translator 與 Speech 要想成整合式 Azure AI Services / Foundry 資源。

Q37Azure Language

Foundry Tools 中 Azure Language 包含哪些三個功能？

你的答案Content Moderator、實體連結、情感分析
正確答案實體連結、PII 偵測、情感分析
白話理解Azure Language 在 AI-900 常考的是文字本身的理解與擷取，例如情感、實體、個資。Content Moderator/Content Safety 是內容安全審核，不是 Azure Language 的核心文字分析功能。

記憶點：Azure Language 常考功能是情感分析、關鍵片語、語言偵測、實體辨識/連結、PII；Content Moderator 是內容安全/審核類。

Q39Prompt Engineering

哪個項目可用來識別產生 AI 模型回應的條件約束和樣式？

你的答案數據關聯
正確答案系統訊息
白話理解如果你要模型「扮演誰、用什麼語氣、不要做什麼、輸出格式長怎樣」，這些規則通常放在系統訊息。資料關聯不是用來控制回答風格的設定。

記憶點：控制角色、語氣、限制、輸出格式，通常是系統訊息；它設定模型回應的上下文。

Q44Embeddings

哪個技術可以搜尋、分類並比較文本來源的相似性？

你的答案機器學習
正確答案嵌入技術
白話理解Embeddings 會把文字轉成數字向量。文字意思越接近，向量距離通常越近，所以可以拿來做語意搜尋、分類、比較相似度。

記憶點：相似度搜尋、語意搜尋、比較文字接近程度，關鍵字就是 Embeddings。

Q48Azure OpenAI

在 Foundry 模型中使用 Azure OpenAI 支援哪種安全能力？

你的答案自訂防火牆規則
正確答案Azure role-based access control (RBAC)
白話理解題目問的是 Azure OpenAI in Foundry Models 支援的安全能力。AI-900 這類題常把「誰可以使用、誰可以管理」對應到 Azure RBAC。

記憶點：Azure 服務的權限管理優先想到 RBAC；題目問「誰能存取、誰能操作」就是 RBAC。
