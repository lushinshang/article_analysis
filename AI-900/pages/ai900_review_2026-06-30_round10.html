滿分確認項目

Vision

Azure Vision 雙選

Azure Vision in Foundry Tools 包含 OCR 與空間分析；實體辨識、關鍵片語、情感分析屬於 Language。

口訣：Vision 雙選 = OCR + 空間分析。
Machine Learning

糖尿病機率題

雖然題目寫「機率的數值」，但用途是判斷患病/風險類別，所以選邏輯斯迴歸。

口訣：是否患病、是否高風險 = 邏輯斯迴歸。
Regression

回歸驗證方向

驗證集用已知特徵產生標籤預測，再與實際標籤值比較；不是用標籤去預測特徵。

口訣：特徵進去，標籤出來，拿實際標籤驗證。
Designer

部署預測服務

使用 Azure Machine Learning Designer 從新訓練模型部署預測服務，先建立推斷管線。

口訣：Designer 訓練 = 管線；Designer 部署 = 推斷管線。
Face

一對多與一對一臉部匹配

一對多用臉部識別，一對一用臉部驗證；臉部屬性只用來判斷眼鏡、頭巾等特徵。

口訣：識別找是誰，驗證比是不是同一人，屬性看配件。
Language

支援問題資料分析

常見問題與主題用關鍵片語擷取；人員、產品、地點、組織用具名實體辨識。

口訣：問題重點 = 關鍵片語；人地物 = NER。
Responsible GenAI

內容篩選層級

抑制有害提示與回應的內容篩選屬於安全系統層，不是模型層或使用者體驗層。

口訣：內容篩選、傷害分類、攔截提示回應 = 安全系統。
Foundry

模型目錄與 Azure OpenAI

Foundry 模型目錄用來發現、比較模型；Azure OpenAI in Foundry Models 常考存取 GPT 與 RBAC。

口訣：模型目錄 = 找模型比模型；Azure OpenAI = GPT + RBAC。
