本輪 8 題錯題明細

Q1Speech / Language

即時簡報的隱藏式輔助字幕，要選哪個工作負載？

你的答案Azure Language in Foundry Tools
正確答案Azure Speech in Foundry Tools
字幕先從聲音轉成文字，所以核心是 Speech，不是 Language。Language 主要是文字分析。

口訣：聲音變文字 = Speech；文字分析 = Language。

Q7Azure Vision

Azure Vision 的專門領域模型支援哪兩個？

你的答案動物、汽車
正確答案名人、地標
這題不是問一般辨識物件，而是問 Vision 的特殊領域模型。

口訣：Azure Vision 專門領域模型 = 名人 + 地標。

Q8Responsible AI

讓所有人都能受益、無論性別或種族，對應哪個原則？

你的答案隱私權和安全性
正確答案包容
這題考的是「所有人都能被賦權並受益」，不是資料保護。

口訣：人人都能用、都能受益 = 包容性。

Q16Azure ML

驗證數據集的用途是什麼？

你的答案數據摘要
正確答案評估訓練好的模型
驗證集是訓練完拿來檢查模型表現，不是拿來做摘要統計。

口訣：驗證集 = 訓練後小考。

Q18Designer

用 Azure Machine Learning designer 部署預測服務，先做什麼？

你的答案新增數據集
正確答案建立推斷管線
題目說的是部署預測服務，代表訓練已經完成，下一步是推斷管線。

口訣：訓練後部署 = 推斷管線。

Q19AutoML

AutoML 檢閱最佳模型後，要讓別人從網際網路使用，下一步是什麼？

你的答案測試已部署的服務
正確答案將模型部署至端點
要先把模型放到端點，外部才有入口可呼叫；測試是在部署之後。

口訣：先部署到端點，再測試。

Q28Azure Face

Face Detect API 幫助辨識配件或頭巾，該看哪個功能？

你的答案臉部識別
正確答案臉部屬性
眼鏡、頭巾、頭飾是臉部特徵或配件，屬於臉部屬性。

口訣：配件 = 臉部屬性；身份 = 臉部識別。

Q34Entity Linking

哪個功能會回傳外部網站連結，消除文本中的歧義？

你的答案關鍵片語擷取
正確答案實體辨識
真正要的是實體連結能力。關鍵片語只抓重點詞，不會提供外部連結來釐清實體。

口訣：外部連結 = 實體連結；重點詞 = 關鍵片語。
